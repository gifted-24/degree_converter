# Degree Converter

A simple command-line tool to convert temperatures between Celsius and Fahrenheit.

## How to Run

1.  **Prerequisites:** Make sure you have Rust installed. If not, you can install it from [rust-lang.org](https://www.rust-lang.org/).
2.  **Clone the repository:**
    ```bash
    git clone gifted-24/degree_converter
    cd degree-converter
    ```
3.  **Run the program:**
    ```bash
    cargo run --release
    ```

The program will then prompt you to choose a conversion direction (Celsius to Fahrenheit or vice-versa) and enter the temperature value.
